# Вимоги до проєкту TechPulse

## 1. Призначення
Веб-застосунок (портал новин ІТ-галузі) для перегляду актуальних статей, фільтрації новин за рубриками, читання та написання коментарів, а також керування контентом.

## 2. Ролі користувачів
- **Відвідувач (Читач)** — перегляд новин, пошук, фільтрація за рубриками, перегляд картки статті, залишення коментарів.
- **Адміністратор (Редактор)** — створення, редагування та видалення статей і рубрик, модерація коментарів.

## 3. Сутності предметної області
| Сутність | Атрибути |
| :--- | :--- |
| Rubric | id, name, slug |
| Article | id, rubric_id, author_id, title, slug, content, image_url, created_at, status |
| Comment | id, article_id, user_id, text, created_at |
| User | id, name, email, password_hash, role |

## 4. Зв’язки
Rubric 1 — ∞ Article; User 1 — ∞ Article; Article 1 — ∞ Comment; User 1 — ∞ Comment

## 5. Сторінки
1. `/` - головна: стрічка новин, популярні статті, банер.
2. `/catalog` - перелік статей: фільтр за рубриками та пошук.
3. `/article/:id` - картка статті: повний текст, блок коментарів.
4. `/article/:id/comment` - форма додавання коментаря (з валідацією).
5. `/login` - сторінка авторизації для адміністратора (та/або користувача).

## 6. Функціональні вимоги
F1. Дані (статті) завантажуються асинхронно з сервера.
F2. Фільтрація за рубриками не перезавантажує сторінку.
F3. Форма коментаря перевіряє ім'я (або email) та текст на порожнечу і мінімальну довжину.

## 7. Нефункціональні вимоги
N1. Адаптивність інтерфейсу від 360 px.
N2. Lighthouse Performance ≥ 85.
